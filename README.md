# 📍 Money Map

**Money Map** is a modern, responsive full-stack financial planning web application tailored specifically for students. It helps users gain control of their finances by allowing them to systematically map out their income, expenses, and monthly budgets before spending. By providing dynamic data visualization and proactive spending tracking, Money Map makes student financial management clear, predictable, and stress-free.

---

## 🚀 Key Features

### 👤 1. Core Financial Dashboard
* **Income Management:** Add multiple income streams (e.g., Pocket Money, Freelancing, Part-time jobs, Scholarships) with title, amount, date, and frequency.
* **Expense & Budget Tracking:** Log expenses against specific student-centric categories and set strict monthly spending caps.
* **Live Balance Calculator:** View real-time metric cards calculating Total Income, Total Expenses, and Remaining Net Balance.

### 📊 2. Dynamic Analytics & Visualization
* **Income vs. Expense Bar Chart:** Visual month-by-month side-by-side comparison tracking macro financial habits.
* **Expense Breakdown Doughnut Chart:** A clean visual breakdown displaying exactly what percentage of funds went to Rent, Food, Books, or Entertainment.
* **Data Portability:** Fully functional custom date filtering with a one-click **"Export Report (CSV)"** download feature to review data inside Excel or Google Sheets.

### ⚙️ 3. Premium Personalization & Settings
* **All Currency Option:** Global localization support. Switch instantly between **PKR (Rs.), USD ($), EUR (€), GBP (£), and SAR (SR)** across all dashboard metrics and chart tooltips.
* **Appearance Configuration:** Seamless, high-performance toggle transitions between a crisp **Light Mode** and a streamlined **Dark Mode**.
* **Custom Category Panel:** Add or delete custom expense/income tags dynamically to tailor the tracking workflow.
* **Data Portability (Backup & Restore):** Secure local state management featuring full JSON format file Exports and Imports to save and recover financial records instantly.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS, Lucide React (Icons)
* **State Management:** React Context API (Global Theme & Currency tracking)
* **Charts & Visualization:** Recharts / Chart.js
* **Data Export Format:** JavaScript Data Blobs (CSV engine)
